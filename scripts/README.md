# Automation and Development Scripts

This directory contains utility scripts for quick developer setup, database seeding, test execution, and demo recording.

---

## Available Scripts

- `seed_data.py`: Populate database with sample exercises, initial therapy plans, and synthetic session history for hackathon demonstration.
- `run_dev.sh` / `run_dev.bat`: Concurrently launch Django backend and Vite frontend.
- `run_tests.sh` / `run_tests.bat`: Run all backend and frontend test suites in a single command.
